# Folder Knowledge Base (MongondowPedia / Bogani AI)

Folder ini khusus disediakan untuk tempat menyimpan file Markdown (`*.md`) pengetahuan umum, sejarah, budaya, geografi, dan dokumen referensi Mongondow.

## 📚 Contoh Struktur File Markdown:

Simpan file dengan ekstensi `.md` (misalnya `sejarah_bogani.md`, `budaya_mongondow.md`, dll):

```markdown
# Sejarah & Pengetahuan Mongondow

## Asal-Usul Bogani
Bogani adalah sebutan untuk pemimpin atau tokoh pemberani yang melindungi masyarakat Mongondow pada masa lampau...

## Tradisi & Budaya
Masyarakat Mongondow memiliki kebudayaan yang kaya meliputi seni tari, hukum adat, dan kearifan lokal...
```

Semua file `.md` yang dimasukkan ke dalam folder ini dapat dibaca oleh sistem untuk melatih basis pengetahuan **Bogani AI**.
