# Folder Data Kamus (MongondowPedia / Bogani AI)

Folder ini khusus disediakan untuk tempat menyimpan file Markdown (`*.md`) kosa kata, istilah, dan terjemahan bahasa Mongondow.

## 📝 Format File yang Disarankan:

Simpan file dengan ekstensi `.md` (misalnya `kosa_kata_harian.md`, `istilah_adat.md`, dll):

```markdown
# Kamus Kosa Kata Mongondow

## A
- **Aka**: Dan
- **Arai**: Hati / Perasaan
- **Ano**: Apa

## B
- **Bogani**: Pahlawan / Pemimpin
- **Biontu**: Sahabat
```

Semua file `.md` yang dimasukkan ke dalam folder ini akan siap diproses dan dipelajari oleh **Bogani AI**.
